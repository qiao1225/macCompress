<h1 align="center">macCompress 压缩小助手</h1>

<p align="center">
  你好呀！我是住在你 Mac 里的原生压缩解压小助手。
  <br />
  干净清爽、随叫随到，帮你把杂乱的文件打包得整整齐齐。
</p>

---

## 朋友们喜欢我的理由

- **3 步搞定，从不废话**：把文件拖给我，选好格式，点一下就开始，没有七拐八绕的复杂弹窗。
- **随处可拖，一触即发**：直接把文件拖进窗口，或者直接扔到屏幕底部的 Dock 图标上，我都会立刻接住并为你准备好。
- **进度看得见，绝不假死**：文件处理到哪一步、还剩几个，我都会真实告诉你（比如：已处理 45/120 个），再也不会让你盯着 95% 发呆猜疑。
- **干活讲究，不留垃圾**：如果你中途按了取消，我会立刻把你桌面上打包了一半的损坏文件收拾干净，桌面干干净净。
- **重名也不怕**：解压时如果发现已有同名文件夹，我会乖乖帮你自动重命名为“（1）”保留两者，或者按你的意思替换覆盖。
- **支持自己起名字**：解压前你可以随心给解压出的文件夹自定义名字，不需要解压完再去手动改名。
- **安全本分**：全程严格使用系统底层原生机制，路径带空格、中文、括号都能稳稳处理，绝不胡乱执行外部命令。

## 能处理哪些格式？

| 格式类型 | 我能帮你打包压缩吗 | 我能帮你提取解压吗 | 说明 |
| :--- | :---: | :---: | :--- |
| **ZIP** | 可以 | 可以 | 最通用，手机电脑都能直接打开，支持设密码和分卷 |
| **TAR / TAR.GZ** | 可以 | 可以 | Linux 与开发者最爱，完整保留文件权限属性 |
| **TAR.BZ2 / TAR.XZ** | 可以 | 可以 | 深度压缩格式，适合把体积压到更小 |
| **7-Zip (.7z)** | 可以 | 可以 | 高压缩比，支持密码加密保护 |
| **DMG / ISO** | 镜像专用 | 可以 | 苹果安装包与光盘镜像，直接只读挂载提取文件 |
| **RAR** | 暂不支持生成 | 可以 | 支持解压 Windows 和网上下载的各种 RAR 压缩包 |

## 怎么把我领回家？

### 直接下载安装（最推荐）
直接在右侧的 **[Releases 页面](https://github.com/qiao1225/macCompress/releases)** 下载 `macCompress.dmg`，双击打开后，把可爱的小图标拖进“应用程序”文件夹，就可以随时在启动台使用啦。

### 访达右键一键压缩
如果你喜欢在访达里直接右键文件操作，可以在终端里运行一行我们准备好的小脚本：
```bash
./Extensions/QuickActions/install_quick_action.sh
```
搞定后，在任意文件上点右键 → 快速操作，就能看到“用 macCompress 压缩”啦。
